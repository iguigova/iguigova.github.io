Style

The base style of every page and document I make, shown with itself.

How it works

One file, brand.css, holds every colour, both themes and the base layout. A project loads it, then adds its own rules on top, and its own rules win.

This page loads that file too. The colours below are read from it as the page opens, so they can't drift from it.

Colours

TokenLightDark

Each value is followed by its contrast against that theme's --bg. Text needs 4.5:1. --title is only for large titles and --rule only for lines and markers, which need 3:1. --hair, --panel and --band are dividers and backgrounds, never text.
